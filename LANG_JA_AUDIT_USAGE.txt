lang=ja 自动审计脚本使用说明
=========================================

文件位置
-----------------------------------------
脚本：./audit-lang-ja.sh
项目钩子模板：./.githooks/pre-commit
本地 Git 钩子：./.git/hooks/pre-commit

用途
-----------------------------------------
用于自动扫描 HTML 中的日文文本标注情况，帮助你发现：
1) 含日文假名（平假名/片假名）的行
2) 疑似遗漏 lang="ja" 语义标注的行

说明：
该脚本是“静态启发式检查”，不会直接改动文件。
疑似结果需要人工复核确认。

运行前提
-----------------------------------------
1) 已安装 ripgrep（命令：rg）
2) 在项目根目录运行，或手动传入目标目录

基础用法
-----------------------------------------
1) 在当前目录审计
   ./audit-lang-ja.sh

2) 审计指定目录
   ./audit-lang-ja.sh /你的项目路径

3) 严格模式（有疑似漏标则返回非 0，用于 CI）
   ./audit-lang-ja.sh --strict
   ./audit-lang-ja.sh --strict /你的项目路径

提交前自动检查（pre-commit）
-----------------------------------------
已为你添加并安装 pre-commit 钩子：
1) 版本可追踪入口：./.githooks/pre-commit
2) Git 实际执行入口：./.git/hooks/pre-commit

工作机制：
- 当你执行 git commit 时，Git 会先运行 pre-commit。
- 钩子会自动执行：
  ./audit-lang-ja.sh --strict <项目根目录>
- 如果检测到“疑似漏标 lang=\"ja\"”项，commit 会被拦截。

如果你未来重装环境或克隆新仓库，可手动重装：
1) chmod +x ./.githooks/pre-commit
2) 复制到 .git/hooks：
   cp ./.githooks/pre-commit ./.git/hooks/pre-commit
3) 赋可执行权限：
   chmod +x ./.git/hooks/pre-commit

输出解读
-----------------------------------------
脚本输出分为两段：

【全部日文命中】
- 列出所有匹配到日文假名的 HTML 行
- 用于全量核对

【疑似漏标 lang="ja"】
- 在“全部命中”的基础上过滤掉：
  - 已含 lang="ja" 的行
  - <ruby> / <rt> 相关行
  - HTML 注释行
- 该列表就是你优先检查的候选项

常见工作流（推荐）
-----------------------------------------
1) 编辑页面后运行：
   ./audit-lang-ja.sh

2) 查看“疑似漏标”列表，逐条确认并补上：
   <span lang="ja">...</span>
   或
   <p lang="ja">...</p>

3) 提交前跑严格模式：
   ./audit-lang-ja.sh --strict
   若退出码非 0，说明仍有候选项未处理。

注意事项
-----------------------------------------
1) 该脚本当前以“假名字符”作为检测入口，
   对“仅汉字构成但语义是日文”的文本不一定能覆盖。

2) 若你后续需要更严谨检测，可扩展规则：
   - 增加词典关键字匹配
   - 增加 DOM 级解析（例如 Node.js + HTML parser）

3) 你的项目中 ruby 已有独立样式策略，
   因此脚本默认将 <ruby>/<rt> 视为白名单。

快速示例
-----------------------------------------
以下写法会被视为通过：
   很多初学者在背诵 <span lang="ja">あいうえお</span> 时会感到困难。
   <p lang="ja">今日はいい天気ですね。</p>

以下写法会被列入“疑似漏标”：
   <p>今日はいい天気ですね。</p>
   <h2>初识木漏れ日</h2>   （如果未包 lang="ja"）
